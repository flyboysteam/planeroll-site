# Planeroll preview site

This is a portable static site: open `index.html` locally for a quick preview, or serve these files from any static host. The email form submits directly to Formspree.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings** → **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the deployment branch (usually `main`) and the **/(root)** folder, then save.
5. GitHub will provide the temporary Pages URL after publishing.

No custom domain or DNS configuration is included.
